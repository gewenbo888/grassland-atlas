# Grassland Atlas · 草原图谱

A multi-scale geographic intelligence platform: **Inner Mongolia → Ulanqab → Chahar Right Front Banner → Tuguiwula Town**. Nine interactive modules treating geography, history, ethnicity, settlement, economy, daily life, infrastructure as layers of one regional system.

## Modules

1. **Multi-Scale Map System** — 4 zoom levels (Province · Prefecture · Banner · Town), each with custom SVG showing terrain/settlements/infrastructure layers and per-scale stats
2. **Geography & Environment** — Mongolian Plateau context, grassland ecology, wind regime; 12-month Tuguiwula climate chart with annual stats
3. **Historical Evolution** — 8-event timeline from Xiongnu (3rd c BCE) → Yuan → Chahar surrender (1635) → Eight Banners (1675) → 走西口 → 1947 autonomy → 1954 banner seat → wind era
4. **Ethnic & Cultural System** — Mongolian (~5%) and Han (~93%) split with language, herding, religion, migration history; 3 festival cards (Naadam, Spring Festival, White Month)
5. **Settlement Structure** — focused profile of 土贵乌拉镇 with etymology, grid orientation, history, 4 stats; "typical day in town" hourly schedule
6. **Economy & Industry** — 5-sector breakdown (animal husbandry, agriculture, energy, manufacturing, services); 3 deep-dive cards (sheep/cattle/dairy, potato capital, wind power)
7. **Daily Life Layer** — 4 windows (Food, Transport, School, Winter Heat) with examples and stats
8. **Regional Connectivity** — radial SVG of 6 connected cities with rail/expressway distinction; full distance/mode/role table
9. **Regional Simulation Engine** — 5 sliders (rainfall, temperature, wind capacity, train pairs, capital infusion) with heuristic effects on population, herding, energy, water, out-migration

## Features

- **Bilingual EN ↔ 中文** instant toggle, localStorage-persisted
- **4 hand-drawn SVG maps**, one per scale, with rail lines, government compounds, lakes, market squares, schools, and grid streets
- **Live simulation engine** with 5 input sliders → 5 output domains, recomputed in real time
- **Honest evidence framing** — disclaimer notes which data is from official sources vs estimation

## Stack

Plain HTML + CSS + vanilla JS — single-file, zero build, Vercel static hosting. EB Garamond + IBM Plex Sans + JetBrains Mono on a steppe-night palette.
